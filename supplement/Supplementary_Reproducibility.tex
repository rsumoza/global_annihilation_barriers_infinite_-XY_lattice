\section{Purpose and mathematical scope}

Revision 7 configures the author-supplied repository address and planned
release links without changing the scientific result. It retains the complete execution and connection audit in
Section 7 and documents the restricted infinite input class in Section 5.
Earlier records are explicitly dated. The frozen scientific sources and
fixed-instance numerical barrier are unchanged.

This record links the inputs, executions and arithmetic checks to the
analytic reductions in the manuscript and the stated arithmetic assumptions.

The unperturbed result concerns one neutral dipole, with charges $+1$ and
$-1$ on plaquettes centered at $(0,0)$ and $(12,0)$, respectively, for the
exact cosine interaction on the infinite square lattice. Each unoriented
nearest-neighbor bond is counted once:
\[
 E(\theta)=\sum_e\bigl(1-\cos D_e\theta\bigr),\qquad
 \|\theta\|_\X=\|D\theta\|_{\ell^2}.
\]
Here $\X$ is the homogeneous energy completion modulo constants, with the
conventions specified in the manuscript. The target set is the set of all
physical uniform lifts,
\[
 \mathcal K=\{u\in\X:D_eu\in2\pi\mathbb Z\text{ for every }e\}.
\]
The minimax ranges over all strong-$\X$ continuous paths from the certified
minimum to $\mathcal K$. No reflection constraint is imposed on the paths
or their transverse perturbations, and the infinite exterior is included.

The certificate establishes, for this configuration,
\[
 B_{\rm ann}=E(s_*)-E(m_*),\qquad
 0.00567867<B_{\rm ann}<0.00570116,
\]
where $s_*$ is either member of the reflected asymmetric index-one saddle
pair. The separating construction uses $109$ charts and $436$ coordinate
faces, with exact-saddle caps and full cutting-plane checks. These are
finite verification objects controlling the full-space problem; they do
not replace it by a finite-box variational problem.

\paragraph{Meaning of reproduction.}
The run documented here used a new extraction and new output directory,
recompiled the original checking sources, and reran the default supervisor.
It reused fixed candidate arrays and proposals. It did not use archived
result files as mathematical premises or resume cached certificates.
This is a fresh reproduction with the same checking software, not a
second, independently implemented interval engine. It is also not a
proof-assistant formalization or external journal peer review.

\paragraph{Reusable a posteriori conditions.}
To apply the method to another configuration, supply finite-energy candidate
representations with certified full-space residuals, branch and exterior
remainders; the finite comparison matrices and their interval inequalities;
the complete boundary ledger; an upper path with analytic exterior control;
and every endpoint/membership check needed by the minimax argument. The
abstract sufficient conditions in the manuscript describe these obligations.
The supplied program is not an unconditional algorithm guaranteed to
certify every configuration. Failure of a sufficient test proves neither
instability nor a cheaper escape.

\paragraph{What a subsequent verification should compare.}
First identify the three input archives by byte count and SHA-256. Then
run the fresh command in a separate output directory, inspect every phase
status and skipped-check field, and retain the produced logs and manifest.
Compare mathematical bounds and final statuses as well as hashes: build
metadata or other harmless output formatting can differ on a new system.
A genuinely independent implementation would additionally reconstruct the
analytic-to-computational reductions and interval operations with a separate
checking codebase. That stronger claim is not made here.
