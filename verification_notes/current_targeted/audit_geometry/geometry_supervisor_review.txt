Geometry review by source location
----------------------------------
A. Closed cuts and tangencies, check_capped_separator.py
   Lines44–45 discard a box only if the lower endpoint of an exact cut
   expression is STRICTLY positive on the entire box. A box with ell=0,
   ell.lo=0 or a sign-straddling interval is retained. Lines66–68 discard a
   disk box only when its squared-radius lower bound is strictly greater
   than the disk upper bound; circle equality stays. Line111 excludes the
   plane only for ell.lo>0 or ell.hi<0, so exact and possible zeros remain.
   This is a sufficient one-cut discard test, not a claimed necessary rule:
   it can keep extra boxes, which affects efficiency, not soundness.
   Lines83–85 and121–123 use [lo,mid] and [mid,hi], so no midpoint or edge
   is omitted. The helper tests confirmed these predicates directly from AST.

B. Full fibers, check_capped_separator.py lines46–53,112–116
   root=beta/mu and R-root>0 establish a unique interior minimizer in the
   complete Hilbert fiber. The orthogonal G-quadratic+Y-distance expression
   encloses ||c_i(a)-s_hat||^2. Adding rho and root gives the sufficient cap
   condition for that minimizer. The cap result then extends to the whole
   closed fiber by strong convexity, even if most of that fiber is farther
   than Rcap from the saddle. This correctly does not freeze transverse
   perturbations and does not need chart minimizers to coincide globally.
   On-plane equality is mathematical (the separator plane passes through s);
   interval strips overcover its possible location. No arbitrary midpoint
   of the offset interval is chosen as the actual plane.

C. Radial walls versus annuli
   check_capped_separator.py lines70–77 evaluates the lower quadratic at
   the EXACT radial wall radius R, so accepting the wall's energy bound
   does not require radial monotonicity. In contrast check_atlas.py
   lines327–331 uses a radius rin to exclude a whole possible low-energy
   annulus; it correctly also requires nonnegative derivative. Thus absence
   of that derivative guard on exact radial walls is not a bug.
   The capped checker explicitly rejects unsupported outer_path charts at
   line104. It cannot silently claim a capped PASS with that unimplemented
   generalized option. The actual 109-chart manifest uses no outer_path.

D. Complete coordinate faces and disk coverage, check_atlas.py
   Lines289–292 initialize all four closed face intervals, including corners.
   Lines306–307 discard only strict disk exterior. Lines317–325 require
   the complete coordinate interval strictly inside a neighbor and strict
   full-ball containment; otherwise lines327–331 verify the energy annulus
   exclusion before using that neighbor. Both cases imply every possible
   below-LEVEL point of the full original fiber lies inside the neighbor.
   At points on the outer coordinate circle, overlap alone is not used to
   eliminate the global boundary: the independent circle test remains.
   Lines348–350 split closed intervals without endpoint loss. Lines384–389
   enumerate every closed nearest-grid Voronoi square meeting the disk with
   <=, and394–400 require strict coordinate coverage / neighbor margins.

E. Interval polynomials
   Poly and TightPoly in check_atlas.py use degree-limited directed rational
   coefficients, interval squares for even powers and an intersection of a
   natural enclosure with a centered mean-value enclosure. For each actual
   polynomial whose coefficient values lie in those intervals, both contain
   its values; coefficient dependency only widens them. Their intersection
   is legitimate. I.rational/endpoints/mul/div/square/sqrt are integer-directed
   operations on a fixed 2^160 grid. No finite sampling substitutes for a
   coordinate-cell inequality in the checker.

F. Membership, certify_cut_membership.py lines6–28
   detG>0 and the archived Gram data provide the inverse matrix enclosure.
   p=(-n1,n0) and n^T a_s=d give
   ||a_s||_2^2=(d^2+(p^T a_s)^2)/(n^T n); the coordinate perturbation bounds
   use Gi dual norms. This avoids replacing the exact saddle by its proposal.
   Lines16–20 check strict coordinate and Y-fiber inclusion in a real chart,
   and23–25 check strict membership in the other saddle halfspace.
   The minimum-cut test centers the minimum at reaction coordinate zero,
   as justified by the shared reference being the original minimum proposal.
   The global supervisor binds that shared reference by exact file hashes.
   Standalone helper acceptance is conditional; its optional --manifest mode
   is not the mode invoked by the global supervisor, which supplies all109
   charts. Empty/duplicate cap defense could be strengthened in this tiny
   helper, but the global frozen supervisor explicitly creates two differently
   named cap entries and the boundary checker requires exactly two. No actual
   frozen-certificate false PASS follows from that generic input hardening.

   Frozen source manifests and raw input pins are checked before building a

Unresolved trust obligations / what cannot be recomputed now
---------------------------------------------------------
The current extension archive includes archived antecedent results and all
extension scientific sources/proposals, but does not duplicate the original
separator/connection input distributions. Their manifests, raw references,
reaction fields, saddle proposal, all 109 raw centers and original verifier
source pins are mandatory to run verify_optimality.py completely. We cannot
freshly certify original residuals, Neumann matrices, exterior/interface
estimates, chart polynomials, original upper-path nodes, or terminal exterior
charge checks from the extension alone. Hash agreement of archived outputs
is evidence of byte identity, not proof that those estimates are correct.

The available data DOES allow the new full Python ledger and membership
replay, rational assembly checks, geometry coverage and source/predicate
review documented above. These are useful and reproducible intermediate
results with an explicitly conditional status. The manuscript should not
label this new replay as an independently implemented or fully fresh global
CAP verification. Conversely, no observed failure of the geometric mechanism
was found here.
